Icon assets in this directory
=============================

The SVG files here are icon artwork from Microsoft's Fluent UI System Icons
project:

    https://github.com/microsoft/fluentui-system-icons

They are redistributed under the MIT License, reproduced below.

Each icon is provided in two colour variants: `<Name>_black.svg` for light
themes and `<Name>_white.svg` for dark themes. Only the fill colour differs.

These files are the icon artwork only. The widget code that renders them lives
in `gui/fluent_compat.py` and is original to Vocal2Midi.

The `chevron_up_*.svg` and `chevron_down_*.svg` files are original to this
project (simple self-drawn arrows for the combo box and spin boxes) and are
covered by the repository's Apache-2.0 license, not the MIT notice below.
